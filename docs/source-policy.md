# ソース方針

## 生成AI業務効率化

一次資料のみを採用します。企業公式の研究・技術文書・製品発表、原著論文、政府・公的研究機関の原資料を対象にします。二次解説は探索の入口には使えても、判断カードの根拠にはしません。

## 日経225・為替

最優先は企業開示、中央銀行、統計当局、政府・規制当局です。メディア記事は背景説明として別ラベルにし、開示・発表本文と混同しません。これは投資助言や売買シグナルを生成する仕組みではありません。

## 著作権と保存

保存する基本単位はURL、メタデータ、短い引用、独自要約、根拠位置です。記事本文・画像・動画の全面複製は、利用条件を確認できた場合に限ります。
